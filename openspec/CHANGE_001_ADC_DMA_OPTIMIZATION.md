## 📋 问题描述

### 问题1：温度升高导致基准电压漂移

| 现象 | 根因 | 影响 |
|------|------|------|
| 高温时电压测量偏移 | VDDA随温度漂移 | 火焰误判 |
| VREFINT读数不稳定 | 轮询采样时序不一致 | 补偿精度下降 |

### 问题2：小火检测失败

| 现象 | 测量值 | 阈值 | 期望 | 实际 |
|------|--------|------|------|------|
| 小火未检测到 | ~2600mV | 2680mV | 有火焰 | 无响应 |

**可能原因分析**：
1. 采样噪声导致电压波动超过阈值
2. 轮询模式采样间隔不稳定
3. VDDA校准不及时，计算电压偏高
4. ADC采样时间不足，读数偏低

### 问题3：当前ADC架构缺陷

```
当前架构（轮询模式）:
┌─────────────────────────────────────────────────────────┐
│ CPU → 启动ADC → 等待转换 → 读取 → 累加 → 循环128次    │
│ 问题：CPU占用高(~70%)，采样时序不一致，易受中断影响   │
└─────────────────────────────────────────────────────────┘
```

---

## ✅ 优化方案

### 方案概述

```
新架构（DMA轮询模式，无中断）:
┌─────────────────────────────────────────────────────────┐
│ ADC连续转换 → DMA自动搬运 → 缓冲区满 → CPU轮询读取    │
│ 优点：CPU占用低(<5%)，采样时序一致，数据可靠          │
└─────────────────────────────────────────────────────────┘

数据流：
ADC_DR ──DMA──> adcDmaBuffer[128] ──CPU轮询──> 平均值计算

通道切换策略（顺序采样）:
┌────────────────────────────────────────────────────────────┐
│ 周期1: VREFINT采样(16次) → 计算VDDA                       │
│ 周期2: PA1火焰采样(128次) → 计算电压 → 火焰判断           │
│ 周期3: 温度传感器采样(32次) → 温度补偿（可选）            │
└────────────────────────────────────────────────────────────┘
```

### 核心改进点

| 改进项 | 旧方案 | 新方案 | 收益 |
|--------|--------|--------|------|
| **ADC模式** | 轮询Poll | DMA(无中断) | CPU降低70% |
| **采样一致性** | 不稳定(1-5ms) | 稳定(<100μs) | 噪声降低 |
| **VREFINT刷新** | 每次循环 | 独立采样周期 | 精度提升 |
| **数据处理** | 逐个累加 | 批量平均+滤波 | 抗干扰增强 |
| **阈值裕量** | 无 | 迟滞区间 | 避免临界误判 |

## 🔧 技术实现

### 1. ADC DMA配置（无中断）

```c
/* DMA配置要点 */
- 模式: 循环模式 (Circular)
- 数据宽度: Half-Word (16bit)
- 内存增量: 使能
- 无中断: 不使能DMA传输完成中断
- 轮询检测: 通过DMA->CNDTR判断传输进度
```

### 2. 双缓冲采样策略

```c
/* 火焰传感器采样缓冲 */
#define ADC_DMA_BUFFER_SIZE    128u
static uint16_t adcDmaBuffer[ADC_DMA_BUFFER_SIZE];

/* VREFINT采样缓冲 */
#define VREFINT_DMA_BUFFER_SIZE 16u
static uint16_t vrefintDmaBuffer[VREFINT_DMA_BUFFER_SIZE];
```

### 3. VREFINT温度补偿增强

```c
/* VREFINT温度系数补偿 */
/* STM32G0 VREFINT典型温漂: 30ppm/°C */
#define VREFINT_TEMP_COEFF_PPM  30
#define VREFINT_REF_TEMP_C      30.0f

float compensateVrefint(uint32_t vrefintRaw, float tempC)
{
    float tempDelta = tempC - VREFINT_REF_TEMP_C;
    float driftFactor = 1.0f + (tempDelta * VREFINT_TEMP_COEFF_PPM / 1e6f);
    return (float)vrefintRaw * driftFactor;
}
```

### 4. 火焰检测迟滞逻辑

```c
/* 迟滞阈值配置 */
#define FLAME_THRESH_LOW_MV    2600u  /* 低于此值确认有火 */
#define FLAME_THRESH_HIGH_MV   2750u  /* 高于此值确认无火 */

/* 迟滞状态机 */
typedef enum {
    FLAME_HYSTERESIS_UNKNOWN,
    FLAME_HYSTERESIS_PRESENT,   /* 火焰存在 */
    FLAME_HYSTERESIS_ABSENT     /* 火焰熄灭 */
} FlameHysteresisState;
```
